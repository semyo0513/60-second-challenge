# 🎯 60초 미션 클리어 챌린지 (독서행사 부스 게임)

> **독서 행사 부스 운영을 위한 60초 미션 챌린지 웹 애플리케이션**  
> 참가자가 랜덤으로 미션을 뽑고, 60초 카운트다운 타이머 속에서 미션을 수행하며, 성공 시 명예의 전당 랭킹보드에 실시간 반영되는 풀패키지 솔루션입니다.

---

## 🌟 주요 특징 및 차별점

1. **몰입감 넘치는 시각 & 청각 연출**
   - **미션 뽑기**: 마법의 책 페이지가 펼쳐지며 룰렛 슬롯이 감속 멈춤되는 스펙터클 연출
   - **60초 타이머**: 대형 SVG 서큘러 프로그레스 링 (녹색 → 황색 → 적색 전이)
   - **긴장감 고조**: 마지막 10초 진입 시 화면 붉은 펄스, 미세 진동, 심장박동 저음 사운드
   - **성공 / 실패 판정**: 골드 파티클 폭죽 + MISSION CLEAR 스탬프 + 팡파레 vs 코믹한 크랙 폭발음 연출
2. **외부 음원 파일 없는 100% 내장 사운드 엔진**
   - Web Audio API 신디사이저(`sound.js`)를 탑재하여 추가 음원 다운로드 없이 즉시 생생한 사운드 출력
3. **현장 진행자(Game Master) 원터치 오버레이 컨트롤러**
   - 화면 우측 하단 마스터 버튼 또는 단축키(`F2` / `Ctrl+M`)로 즉시 판정(성공/실패/초기화) 가능
4. **강력한 관리자 대시보드 (`admin.html`) & 구글 시트 양방향 연동**
   - **웹 화면**: 미션 등록 / 수정 / 삭제 / 활성화 토글 / 독서미션 추천 20종 일괄 추가
   - **구글 시트 직접 편집**: `Missions` 및 `Settings` 시트에 행을 직접 작성/수정해도 게임 화면에 실시간 자동 반영
   - 행사 타이틀, 타이머 시간, 관리자 PIN, 재뽑기(Pass) 허용, 사운드 볼륨 설정
   - 랭킹 관리 및 성공/실패 전체 시도 로그 통계 & CSV 내보내기
5. **Google Sheets DB + 로컬 오프라인 듀얼 지원**
   - Google Apps Script를 통해 구글 시트 4종(`Missions`, `Rankings`, `GameLog`, `Settings`)과 실시간 연동
   - 네트워크 연결이 없어도 `localStorage` 기반 오프라인 모드로 100% 완벽 동작

## 📊 구글 스프레드시트에서 직접 수정하는 방법

구글 스프레드시트에서 직접 데이터를 편집해도 웹앱에 완벽하게 반영됩니다.

### 1. `Missions` 시트 (미션 목록)
| 컬럼 | 항목명 | 설명 | 예시 |
|---|---|---|---|
| A열 | ID | 고유 식별자 (비워두면 자동 부여) | `M001` |
| B열 | 미션내용 | 화면에 표시될 미션 텍스트 (필수) | `책 5권을 쓰러지지 않게 쌓기` |
| C열 | 카테고리 | 찾기, 말하기, 낭독, 신체, 퀴즈, 일반 등 | `신체` |
| D열 | 난이도 | 하, 중, 상 | `중` |
| E열 | 사용여부 | `TRUE` / `FALSE` (또는 비워두면 사용) | `TRUE` |
| F열 | 등록일시 | 등록 시점 기록 | `2026-09-14 17:00:00` |

### 2. `Settings` 시트 (게임 환경 설정)
| 항목(A열) | 값(B열) | 설명 |
|---|---|---|
| `이벤트명` | 📚 60초 독서 미션 챌린지 | 화면 상단 및 대기화면 메인 제목 |
| `서브타이틀` | 책 속의 미션을 60초 안에 클리어하라! | 대기화면 부제목 안내 문구 |
| `타이머초` | `60` | 챌린지 제한시간 (초 단위 숫자) |
| `관리자PIN` | `1234` | 관리자 대시보드 접속 비밀번호 |
| `재도전허용` | `TRUE` | 미션 1회 재뽑기(Pass) 기능 허용 (`TRUE`/`FALSE`) |
| `자동복귀초` | `5` | 결과 화면 후 대기 화면으로 자동 복귀할 시간(초) |
| `사운드볼륨` | `80` | 게임 기본 효과음 볼륨 (0~100) |

## ☁️ Google Sheets + Apps Script 백엔드 연동 가이드

### 1단계: 새 구글 스프레드시트 생성
1. [Google Sheets](https://sheets.new)에 접속하여 새 스프레드시트를 만듭니다. (제목 예: `2026 독서행사 미션 챌린지 DB`)
2. 상단 메뉴에서 **[확장 프로그램] → [Apps Script]**를 클릭합니다.

### 2단계: `Code.gs` 코드 복사 & 붙여넣기
1. 프로젝트 내의 `Code.gs` 파일 내용을 복사하여 Apps Script 에디터에 붙여넣고 저장합니다.

### 3단계: 웹 앱으로 배포
1. Apps Script 우측 상단 **[배포] → [새 배포]**를 클릭합니다.
2. 유형 선택(톱니바퀴)에서 **[웹 앱]**을 선택합니다.
   - **설명**: `60초 미션 챌린지 API`
   - **다음 사용자로 실행**: `나 (내 계정)`
   - **액세스 권한이 있는 사용자**: `모든 사용자` (⚠️ 중요: 익명 참가자 접근을 위해 필수)
3. **[배포]** 버튼을 누르고 권한 승인을 완료합니다.
4. 배포 완료 후 발급되는 **웹 앱 URL (`https://script.google.com/macros/s/.../exec`)**을 복사합니다.

### 4단계: `config.js`에 URL 입력
`config.js` 파일을 열고 복사한 URL을 입력합니다:
```javascript
const CONFIG = {
  GAS_API_URL: "https://script.google.com/macros/s/YOUR_DEPLOYED_ID/exec",
  // ...
};
```

## 🌐 GitHub Pages 배포 방법

1. GitHub에 새 저장소(예: `60-second-challenge`)를 생성합니다.
2. 모든 파일(`index.html`, `admin.html`, `style.css`, `script.js`, `sound.js`, `config.js` 등)을 저장소에 Push합니다.
3. 저장소 **Settings** → **Pages** 메뉴로 이동합니다.
4. **Branch**를 `main` (또는 `master`), 폴더를 `/ (root)`로 선택하고 **Save**를 클릭합니다.
5. 몇 분 후 제공되는 GitHub Pages URL로 부스 화면을 띄울 수 있습니다.

## ⌨️ 현장 운영 단축키 안내

| 키 | 동작 |
|---|---|
| `Space` | 다음 단계 진행 (대기화면→도전자등록 / 미션준비→타이머시작 / 타이머중→성공판정) |
| `Escape` | 현재 상태 취소 및 대기 화면으로 즉시 리셋 |
| `F2` 또는 `Ctrl + M` | 현장 진행자 마스터 오버레이 패널 열기/닫기 |
| `M` | 음소거(Mute) 켜기/끄기 토글 |
| `F` | 빔프로젝터/모니터 전체화면(Fullscreen) 토글 |
